Earth & Weather Intelligence (PoC)

気象データ(気圧・気温・降水量・湿度・風速)と地震データを共通の時間軸で可視化し、統計的な相関/非相関を検証する。WAIO EARTHWEATHER worker / earth_weather/ パイプラインの出力を表示するダッシュボード。

相関 ≠ 因果関係 -- このページが示す数値は、気象変数と地震活動のあいだに統計的な関連が観測されたかどうかだけを示す。地震が気象によって引き起こされる(あるいはその逆)ことを示す根拠では一切ない。多重比較(複数変数×複数ラグの同時検定)により、偶然の見かけ上の有意差が生じ得る点にも注意。詳細は下部の caveats を参照。

caveats

Display layer only -- reads earth_weather/data/timeline_latest.json, earth_weather/data/correlation_report.json and earth_weather/data/intelligence_summary.json (generated by the earth_weather/ pipeline, see ARCHITECTURE.md) when served over HTTP. Falls back to the last real pipeline run embedded below when opened directly via file://. No external network requests are made by this page (no CDN, no fonts, no analytics). To view live data: python3 -m http.server from the repo root, then open http://localhost:8000/dashboard/earth_weather.html. Run ./waio.sh -w EARTHWEATHER "run" (or ./earth_weather/run_pipeline.sh directly) first to refresh the data. 気象警報等はキーレス提供元(Open-Meteo)からは取得できないため、このダッシュボードには含まれていない(データ欠損として明示)。
